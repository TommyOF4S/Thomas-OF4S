Use CET's PDF export: the page reads every panel joint (straight, corner, T, cross, free end) and quotes the connectors from it. A PNG or JPG is shown beside the flags.

Height changes: in CET, put a red dot on each joint where the panel height changes and a label beside it with the two heights, like 47/53. Each red dot is quoted as a change-of-height connector kit (HMA224) plus the matching high/low filler strip (HMHL4753), in place of that joint's panel-to-panel connector.
